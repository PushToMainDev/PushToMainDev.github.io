Approach

How we build

Private by design

Access rules live in the database, not just the app. People see only what they're meant to see.

Native on every platform

SwiftUI on iPhone and native Android, so each app looks and feels at home on the device in your hand.

Tested before it ships

Automated tests and regression checks run on every release, so updates add features without breaking what people rely on.
